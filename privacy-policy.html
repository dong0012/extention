Privacy Policy for ScrollNerd

Effective date: May 6, 2026

ScrollNerd is a browser extension that provides a floating scrolling assistant for web pages. This Privacy Policy explains what information the extension collects, how it is used, and how it is handled.

Information We Collect

ScrollNerd does not collect, transmit, sell, or share personal information.

The extension does not collect browsing history, account credentials, personal communications, health information, financial information, precise location, or personally identifiable information.

How the Extension Uses Data

ScrollNerd may use local browser storage only to save extension preferences, such as the position of the floating widget or other user interface settings. This information stays on the user's device and is not sent to any remote server.

Permissions

  • Host permissions: used so the extension can run on supported web pages and display the floating scrolling assistant.
  • Storage permission: used to save local extension preferences if needed.
  • Tabs permission: if present, it is used only to support extension behavior in the currently active tab.

Remote Code

ScrollNerd does not use remote code. All executable code is packaged within the extension distributed to users.

Third-Party Services

ScrollNerd does not send user data to third-party services for analytics, advertising, profiling, or tracking.

Data Retention

Because ScrollNerd does not collect personal data, it does not retain personal data on external servers.

Changes to This Policy

This Privacy Policy may be updated from time to time to reflect product changes or legal requirements. Any updates will be posted on this page with a revised effective date.
